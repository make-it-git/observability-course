# Домашнее задание: Анализ паттернов метрик для создания алертов

## 

**Цель:** Научиться выявлять разные аномалии в метриках.

---

### Задача

Проект находится в репозитории: [https://github.com/make-it-git/observability-course/tree/main/homework/new/lesson_07/project](https://github.com/make-it-git/observability-course/tree/main/homework/new/lesson_07/project)

Он представляет собой генератор метрик, который экспортирует следующие метрики:
* `linear_metric`: Gauge, значение которой линейно возрастает во времени.
* `sinusoidal_metric`: Gauge, значение которой изменяется по синусоидальному закону (сезонный паттерн).
* `spike_metric`: Gauge, значение которой характеризуется редкими, но значительными всплесками.

Паттерн в метрике меняется через 5 минут после запуска. Вам нужно понять, как покрыть именно этот интервал после прохождения 5-минутного интервала, т.к. дальше паттерн меняться не будет.

Для простоты достаточно нарисовать график, где показано оригинальное значение метрики и линию, которая показывает наличие алерта в нужном временном интервале.

---

### Вам нужно:

Для каждой метрики разработайте запросы, способные обнаружить следующие "отклонения" от нормального поведения:

1. **`linear_metric`:** Обнаружение замедления темпа роста. Запрос должен сигнализировать, если производная метрики (скорость изменения) значительно уменьшается по сравнению с историческими значениями.
2. **`sinusoidal_metric`:** Обнаружение отклонения от сезонного паттерна. Ключевой аспект — сравнение текущего значения с ожидаемым значением, основанным на исторических данных.
    * *Примечание:* Для упрощения задачи предположим, что сезонность (цикл) меняется через 5 минут. В реальных сценариях это может быть, например, недельный цикл, где необходимо сравнивать текущее значение с тем, что было неделю назад в то же время.
    * Используйте функции `offset`, `avg_over_time` и их комбинации для сравнения текущих значений с историческими данными.
3. **`spike_metric`:** Обнаружение всплесков. Запрос должен сигнализировать о значительном увеличении значения метрики по сравнению с ее обычным диапазоном. Используйте скользящие средние или стандартные отклонения для определения порогов.
